# Inbox

Jogue aqui qualquer coisa: ideia, link, anotação solta. Uma nota por item, nome livre.

O loop noturno arquiva sozinho o que tem destino óbvio e deixa como proposta só o que é ambíguo. `/processar-inbox` faz o mesmo na hora, se você quiser.
